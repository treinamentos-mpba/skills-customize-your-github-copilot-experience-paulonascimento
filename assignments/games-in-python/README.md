
# 📘 Atividade: Jogo da Forca

## 🎯 Objetivo

Pratique manipulação de strings, loops, condicionais e seleção aleatória ao construir um jogo da Forca em Python. O jogador deverá revelar uma palavra oculta antes de esgotar as tentativas disponíveis.

## 📝 Tarefas

### 🛠️ Implementar o jogo da Forca

#### Descrição
Crie um jogo em que o programa seleciona uma palavra secreta e o jogador tenta descobri-la informando letras.

#### Requisitos
O programa concluído deve:

- Selecionar aleatoriamente uma palavra de uma lista predefinida.
- Mostrar cada letra ainda não descoberta como um sublinhado, separando as posições (por exemplo, `_ _ _ _`).
- Atualizar e exibir o progresso após cada palpite válido.

### 🛠️ Controlar palpites e encerrar a partida

#### Descrição
Controle as tentativas do jogador e finalize a partida quando a palavra for descoberta ou não houver mais tentativas disponíveis.

#### Requisitos
O programa concluído deve:

- Rastrear e informar quantas tentativas incorretas restam.
- Encerrar a partida quando todas as letras da palavra forem descobertas ou as tentativas incorretas chegarem a zero.
- Exibir uma mensagem de vitória ou derrota e revelar a palavra secreta ao final.
